## Objetivo

## .gitignore
O arquivo \`.gitignore\` deste projeto foi configurado para evitar o versionamento acidental de arquivos temporários, logs e produtos de compilação: \* \*\*\`\*.log\`\*\*: Ignora arquivos de registros de erros ou execuções gerados localmente. \* \*\*\`/\*.DS\_Store\`\*\* e \*\*\`pycache\`\*\*: Suprime arquivos e diretórios de cache temporários do sistema operacional. \* \*\*\`/build\`\*\*: Evita o envio de artefatos de compilação que podem ser reconstruídos localmente. \* \*\*\`/.user\`\*\*: Impede que arquivos com preferências pessoais de IDEs e editores subam para o repositório compartilhado.

Exercitar conceitos de lógica de programação e orientação a objetos.

## Como executar

Execute a classe principal do projeto em uma IDE Java.
